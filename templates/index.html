What happens when you press Send
  • The browser posts the text to Flask under {{ request.script_root or '/' }}.
  • Flask saves your message in MySQL and reads the earlier messages of the same chat.
  • The whole conversation goes to Ollama, which generates the answer on the server's own hardware.
  • Flask saves the answer and sends it back. app.js adds it to the chat.
  • New chat starts a fresh conversation, so the model forgets the old one.

03 The pipeline

git push tests deploy restart live
  1. Push to main A push to main on GitHub starts the workflow. Nobody copies files by hand.
  2. Tests The Python tests run on a clean runner. One failing test stops the pipeline here, before anything reaches the server.
  3. Deploy The workflow connects to the server over SSH with its own key and pulls the new code.
  4. Restart systemd restarts Gunicorn. Nginx and Ollama keep running.
  5. Check A final curl makes sure the page answers with 200.

Secrets stay out of the repo

The SSH key and the database password are stored as GitHub secrets and in a root-only file on the server. The repository only has an .env.example.
